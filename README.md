+## Building toward useful software
+
+I care about tools that reduce friction instead of adding another dashboard.
+
+- **Developer infrastructure** — APIs, data flows, background work, and systems that remain understandable under pressure.
+- **AI-agent tooling** — safer handoffs, durable context, test evidence, and practical automation for coding agents.
+- **Local-first software** — useful without an account, predictable without hidden telemetry, and easy to inspect.
+- **Networking** — services, protocols, and the boring reliability work that keeps software connected.
+
+## Current direction
+
+I’m building a focused open-source toolkit for people who work with coding agents.
+
+| Project | What it will solve |
+| --- | --- |
+| **Agent Proof** | Turn an AI-agent run into reviewable evidence: changed files, executed commands, test results, unresolved risks, and a clean handoff. |
+| **Context Signal** | Detect stale, conflicting, oversized, or missing context files before they confuse an agent or a contributor. |
+| **Repo First Aid** | Diagnose setup, environment, Git hygiene, build, and test problems in a repository before they waste an afternoon. |
+
+> The goal: tools that work with your existing stack — not another closed platform to migrate into.
+
+## Principles
+
+```text
+Useful > clever
+Local-first > account-first
+Evidence > “it should work”
+Small tools > bloated platforms
+Clear failures > false success
+```
